# FoodNow Stripe marketplace demo

Java/Spring Boot demo with diner, restaurant, courier and operations workspaces, Stripe Payments, Radar evidence and Connect partner transfers.

The application is in [`foodnow-demo/`](foodnow-demo/).

- [Setup and sample accounts](foodnow-demo/README.md)
- [Run the demo again](foodnow-demo/docs/RUN-AGAIN.md)
- [Presentation walkthrough](foodnow-demo/docs/DEMO-SCRIPT.md)
- [Architecture](foodnow-demo/docs/ARCHITECTURE.md)
- [Verification and limitations](foodnow-demo/docs/VERIFICATION.md)

Requires JDK 25+, Maven, Python 3 and Stripe CLI for test webhooks. Credentials, connected-account mappings and runtime transaction data are excluded from Git. Follow the fresh-clone instructions before starting on another computer.
